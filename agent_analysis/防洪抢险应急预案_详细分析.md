#### 2.3 水文

**流域水文站网**：
- 基本站：柳林水文站（上游12km，1971年至今）

**报汛方式**：
- 有线：固定电话、传真机、网络通讯
- 无线：手机、超短波防汛专用电台、卫星电话

**洪水预报方法**（三种方法结合）：

1. **气象服务平台法**
   - 获取流域点雨量、面雨量
   - 采用经验公式预报洪水总量
   - 结合西安水文局预报的洪峰流量

2. **柳林水文站实测流量法**
   - 按控制面积比例折算入库流量
   - 公式：Q_桃 = Q_柳 × (S_桃 / S_柳) = 1.23 × Q_柳
   - S_桃 = 1335km²，S_柳 = 1179km²

3. **库容曲线法**
   - 监测库水位变化
   - 按库容曲线推算实际入库流量和洪量

**预报流程**：
```
气象数据 → 经验公式 → 洪水总量
    ↓
西安水文局预报 → 洪峰流量
    ↓
柳林站实测 → 入库流量折算
    ↓
库水位监测 → 库容曲线验证
    ↓
综合判断 → 洪水量级 → 防御方案
```

**AI价值**：这是四预智能体的核心输入，三种预报方法可融合为深度学习模型的多源输入特征

### 第3章 工程险情及危害性分析（10页）

#### 3.1 工程险情分析

**3.1.1 导致险情的因素**

1. 发生超设防标准洪水
2. 水库枢纽建筑物工程隐患
3. 地质灾害或地震灾害

**3.1.2 水库工程出现险情的种类、发生部位和危害程度**

**（1）超标准洪水**

**触发条件**：
- 气象部门预报24小时面雨量>260mm 或 6小时面雨量>190mm
- 启动特别严重预警级别

**险情发展链**：
```
超标准洪水 → 库水位达790.5m仍上涨 → 漫顶冲刷坝坡 → 垮坝
    ↓
高水位长期运行 → 大坝变形增大 → 薄弱层裂缝快速发展 → 浸润线抬升
    ↓
异常渗流/渗透破坏 → 坝体失稳 → 垮坝
    ↓
下泄流量>下游河道行洪标准 → 洪水漫堤 → 重大洪水灾害
```

**影响范围**：下游9.20万群众生命财产安全

**（2）水库枢纽工程病险隐患险情**

**① 大坝坝体裂缝**

**历史记录**：
- 1998年、2000年探测：左坝肩背水坡0+104m（782m高程）存在不均匀沉降横向裂缝
- 其他部位存在裂缝密集带
- 2003年除险加固：充填灌浆处理
- 2016年：背水坡出现纵向裂缝，开挖回填加固

**风险演化**：
```
外部条件突变 → 裂缝重生发展纵横贯通 → 集中渗漏
    ↓
管涌、流土 → 坝体冲刷失稳 → 垮坝 → 溃坝洪水灾害
```

**② 近坝岸坡滑坡**

**A. 溢洪道右岸高边坡不稳定**
- 1974年：发生滑坡
- 1990年：滑坡裂缝继续发展
- 1992年：削坡减载处理
- 1996年：开始监测和稳定性分析
- 2003年：再次削坡减载
- 2007年：布设测缝计4套、表面变形观测桩5组10个
- 2024年：钢索锚固处理，增设多点位移计、锚索拉力计

**地质原因**：基岩存在泥质页岩软弱层，上部土质边坡厚重

**B. 溢洪道、输（泄）水洞进出口滑坡**
- 地质条件：湿陷性黄土与灰岩层间夹泥质页岩层
- 泥质页岩易风化、承载力低、遇水强度大幅减弱
- 触发条件：地震或连阴雨

**滑坡后果链**：
```
高边坡坍塌/滑坡 → 堵塞高低放水洞/放水塔/隧洞进口
    ↓
压盖溢洪道泄洪闸门 → 所有泄洪闸门不能正常启闭
    ↓
泄槽段边坡垮塌 → 阻塞溢洪道 → 影响正常运行
    ↓
水库不能正常泄洪 → 库水位不断升高 → 防洪度汛安全威胁
```

**③ 坝前区漏水点和绕坝渗流异常**

**地质背景**：
- 灰岩喀斯特地质地貌
- 灰岩岩溶和裂隙发育
- 古煤井因素影响

**历史处理**：
- 初次蓄水：大规模库区渗漏
- 1970-1980年代：5次大规模库区渗漏专项治理
- 2005年：模袋混凝土岸坡防护、土工膜布防渗补漏
- 每年：小规模铺包补漏（漏水坑点和岸边裂缝）

**风险演化**：
```
高水位长期运行 → 岸坡渗漏漏斗形塌坑/渗漏裂缝
    ↓
防渗铺盖层被击穿 → 漏水点形成
    ↓
绕坝渗流测压管水位上升 → 加剧绕坝渗流
    ↓
抬高坝后浸润线 → 左右坝肩接触渗流破坏 → 坝基/坝坡渗透破坏
    ↓
坝体整体冲刷失稳 → 跨坝
```

**④ 坝体渗透破坏**

**四种险情形态**：

1. **迎水坡失稳**
   - 高水位运行 → 浸润线较高 → 水位骤降 → 渗透内压力 → 冲刷滑坡

2. **背水坡渗漏和失稳**
   - 防渗薄弱层/裂缝 → 高水位 → 浸润线高于设计值 → 渗水/滑坡
   - 沿裂缝集中渗漏破坏

3. **浸润线渗出点偏高**
   - 排水棱体堵塞/下游河道水位过高 → 浸润线高于堆石棱体顶 → 流土渗透破坏

4. **渗透坡降超标**
   - 坝体/坝基渗透坡降超过设计允许值 → 流土/管涌 → 坝肩接触性渗透破坏

**⑤ 溢洪道出口水流冲刷**

**易冲刷部位**：护岸、大坝迎水坡、泄水建筑物消能设施

**冲刷类型**：
- 风浪冲刷：大坝迎水坡及护坡
- 水流冲刷：溢洪道出口河床和岸坡

**地质条件**：
- 风化弱风化石灰岩层
- 上覆砂卵石层（左岸较厚）
- 挑流消能方式

**风险**：
```
大流量泄洪 → 挑流鼻坎下游冲刷坑（十余米深） → 岸坡垮塌
    ↓
基岩垮塌 → 挑流鼻坎安全受威胁
    ↓
岸坡垮塌阻塞低洞工作闸 → 低洞不能泄洪 → 河道水位抬升 → 加剧岸坡垮塌
```

**历史验证**：
- 建成后溢洪道共泄洪19次，历时261天
- 最大泄洪量：200m³/s
- 岸坡冲刷程度并不严重
- 但不排除更大流量情况下出现以上情况

**（3）地震灾害**

**震损评估模型**：
| 震级 | 震损程度 | 影响范围 |
|-----|---------|---------|
| <4级 | 基本未震损 | - |
| 4-6级 | 极有可能部分震损 | 200km |

**各类险情处置措施**：

**（1）坝肩出现渗漏险情**
- 修筑贴坡式反滤层和导渗沟
- 清除渗水出流和浸湿范围地表杂物，向外扩大5-10米

- 土料和块石补坡固脚

**（2）大坝护坡塌陷**

**情形分类**：
- 上游护坡：风浪掏刷、剥蚀、松动脱落、架空坍塌、错动、开裂
- 冰冻引起：鼓胀隆起、坍塌下滑
- 雨水冲刷：雨淋沟、陡坎、坍塌

**处置原则**：抓紧翻筑抢护，防止险情扩大

**处置方法**：
- 风浪掏刷：填补翻修，翻挖分层填土夯实
- 冰冻：加厚砌石护坡反滤垫层、涂黑混凝土板、铺保温板
- 雨水冲刷：削坡、开挖回填、做好坝面排水沟

**（3）大坝滑坡**

**征兆判断**：
- 坝体短时间持续显著位移
- 裂缝出现连续性位移且逐渐加大
- 边坡下部水平位移>上部水平位移
- 边坡上部垂直位移向下，下部垂直位移向上
- 滑动主裂缝两端向下弯曲
- 主缝上下侧有错动

**处置原则**：下部压重，上部减载

**处置方法**：
- 开挖回填、加培缓坡、压重固脚、导渗排水
- 塑料薄膜/土工膜覆盖封闭滑坡裂缝
- 裂缝上方开挖截水沟
- 高水位/渗漏引起的下游滑坡：防渗处理+下游排水反滤
- 小滑坡体：全部挖除，原设计土料分层回填夯实
- 大滑坡体：松土挖除，原设计土料分层回填夯实
- 陡边坡滑坡：放缓坝坡
- 滑坡体底部前缘滑出：砌石固脚或抛石压脚
- 风浪掏刷：翻挖分层填土夯实，防风浪淘刷护坡
- 地震滑坡：开挖回填、放缓坝坡、压重固脚
- 两岸坝肩滑坡：查明原因，结合绕坝渗漏处置
- 下游坝脚冲刷/鱼塘侵蚀：防冲防侵蚀+开挖回填

**（4）大坝裂缝的抢护**

**① 横向裂缝**
- 裂缝在迎水坝坡水面以上或背水坡，深度<5m
  - 开挖回填（深度>裂缝+0.5m，宽度1-2m，长度超两端1m）
  - 或沿槽底缝铺防渗薄膜压填
- 裂缝在迎水坝坡水面以下，深度不大
  - 横墙隔断法（开挖坑槽3-5m×1.5-2m，深度至缝底下0.5m）
  - 坑槽壁面挂铺防渗薄膜，填土夯实
  - 裂缝临水相通时，上游做前戗截流
- 横向裂缝深度较大
  - 降低库水位到裂缝以下
  - 充填灌浆

**② 纵向裂缝**
- 较宽较深或与横向裂缝连通
  - 开挖回填（深度至裂缝下0.3-0.5m，底宽≥0.5m，长度超两端2m）
- 时间紧迫
  - 沿裂缝开挖浅槽回填
- 较窄较浅或龟纹裂缝
  - 一般可不处理，封堵缝口防雨水侵入

**③ 非滑坡性深度中等裂缝**
- 库水位较高，开挖困难
  - 开挖回填与灌浆相结合
  - 上部开挖回填（约2m）
  - 下部灌浆（预埋灌浆管）

**（5）土坝集中漏水的抢护**

**原则**：上堵下排，临背并举

**寻找漏水洞口方法**：
- 水面观察（水深较浅、无风浪时）
- 撒麦麸、谷糠、锯末等漂浮物查找漩涡

**① 封堵进水口方法——临水堵洞**

**A. 洞口较小**：软楔或草捆堵塞
- 漏洞进水口水下埋深较浅、人可以接近、洞口土质较硬
- 软楔（圆锥形网罩，网格约10cm，内填麦秸/稻草，裹填粘土）
- 小头向洞口塞入
- 棉被或篷布铺盖，土袋压牢
- 粘土封堵闭气

**B. 洞口较大**：盖堵法
- 软帘、铁锅、篷布等盖堵进口
- 铁锅正扣或反扣在漏水洞上，胶泥封闭
- 洞口土质松软或周围多裂缝：草帘或篷布重叠数层作为软帘
- 软帘上边绳索系牢于坝顶木桩，下面坠以重物

**② 背水导渗**
- 反滤压盖
- 透水压渗台（出口小而多）
- 反滤围井（集中的大洞）

**③ 降低库水位**
- 开启泄水洞或溢洪道降低库水位到渗水进口以下

**（6）土坝渗水抢护**

**原则**：查明原因和险情程度，综合分析

**处理决策树**：
```
背水坡渗少量清水 + 无发展 + 水位不再上涨
    → 加强观察，暂不处理
    
背水坡渗水严重或已出现浑浊 + 预报水位还要上涨
    → 及时抢护
```

**临水截渗方法**：

**① 土工膜截渗**
- 水深较浅、缺少粘性土料时采用
- 土工膜沿边坡宽度满铺渗水段并深入临水坡脚以外1m以上
- 搭接长度>0.5m
- 卷在8-10m滚筒上，置于临水面堤坝肩
- 土工膜下边折叠粘牢形成卷筒，插入直径4-5cm钢管加重
- 土工膜上压1-2层装有土或沙石的土工膜袋

**② 土袋（柳桩）前戗截渗**
- 库水位较浅时采用
- 临水土坝脚以外用土袋筑隔墙
- 或打木桩一排（桩距1m，桩长根据水深，打入土中1m，桩顶高出水面约1m）
- 木桩上编织柳枝/芦苇篱笆或挂芦席、草席
- 清理边坡，备足土料

**③ 降低库水位**
- 开启泄水洞或溢洪道

**（7）管涌、流土抢护的措施**

**① 反滤压盖**
- 适用：管涌或流土处数较多、面积较大、连成片、渗水涌沙严重
- 清理地基（清除尖棱石块和杂物）
- A. 土工织物反滤压盖：铺土工织物→砂石透水料→块石或沙袋
- B. 砂石反滤压盖：粗砂20cm→小石子20cm→大石子20cm→块石保护

**② 透水压渗台**
- 适用：管涌/流土较多、范围较大、反滤料缺乏、沙土料源丰富
- 用透水性大的沙土修筑平台
- 尺寸根据地基土质条件、渗压分布、土料物理力学性能分析确定

**③ 流土抢护**
- 隆起部位铺麦秸/稻草10-20cm
- 其上铺柳枝20-30cm
- 厚度超30cm时横竖分层铺放
- 压土袋或块石

**④ 降低库水位**

**（8）溢洪泄水建筑物损坏的抢护**

- 降低扬压力：上游加强防渗，下游改善排水
- 表面破坏：水泥速凝砂浆或环氧砂浆修补

**（9）高边坡滑坡的抢护**

**措施**：
- 削坡减载：3-5台挖掘机+装载机，6-12辆自卸汽车，从上至下挖土减载
- 清理垮塌土体，恢复工程功能
- 滑坡阻塞溢洪道：低洞作为主要泄洪建筑物→清除滑塌体→削坡减载
- 建筑物损毁：清理土体+拆除损毁闸门→削坡减载→限制蓄水→专项评估→恢复重建

### 第7章 应急响应（5页）

#### 7.1 响应等级体系

**总体原则**：
根据水情、雨情、工情严重程度和影响范围，结合下游防洪对象、水库调度运用实际，由轻到重划分为Ⅳ、Ⅲ、Ⅱ、Ⅰ四级响应等级。

**7.1 Ⅳ级响应**

**启动条件**（任一）：
1. 水库发生一般洪水（20年一遇及以下）
2. 大坝出现浅层裂缝；下游坡出现多处渗水点；溢洪道有1孔闸门无法开启并可能遭遇强降雨；其他不可预见的可能危及工程安全的一般险情
3. 其他需要启动Ⅳ级响应的情况

**启动人**：桃曲坡水库灌溉中心主任审核批准

**响应措施**：
1. 中心灌溉科组织会商会，制定调度方案，通报险情和调度方案
2. 枢纽站、马栏站按调度方案控制闸门，24小时值守查险
3. 铜川市防汛抗旱指挥部做好河道巡查、抢险准备
4. 区防汛办做好泄洪检查和巡堤查险，向沿岸乡镇发布泄洪通知，禁止河道内与防洪无关活动
