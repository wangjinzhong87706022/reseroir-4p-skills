## 一、六类巡检对象×检查项

### 1. 坝体（13 项）

| # | 检查项 |
|---|---|
| 1 | 裂缝（尤其坝体与岸坡连接部位、异性材料结合部位） |
| 2 | 排水设备（排水沟、截水沟、集水井有无损坏/裂缝漏水/阻塞） |
| 3 | 动物洞穴、有害虫害兽活动迹象 |
| 4 | 滑坡、坍塌、塌陷、隆起 |
| 5 | 蚁穴、鼠洞 |
| 6 | 背水坡散浸、集中渗流、裂缝、滑坡 |
| 7 | 草皮护坡冲沟、鼠洞；坝脚坝肩渗流异常、管涌、流土 |
| 8 | 排水棱体护面裂缝、塌陷、滑坡 |
| 9 | 迎水坡干砌石护坡松动、塌陷、垫层流失、石块架空/翻起（持探水杆沿水边探摸） |
| 10 | 防浪墙裂缝、变形、沉陷、倾斜 |
| 11 | 坝顶路面坑洼、排水畅通、冲沟 |
| 12 | 坝轴线位移或沉降；观测桩、测压管完好 |
| 13 | 坝前区漏水点 |

### 2. 放水洞（进水口/洞身/出口/消能）

| 部位 | 检查项 |
|---|---|
| 进水口 | 放水塔塔体（竖井）裂缝、渗水、损坏；工作桥移位、裂缝、结构牢固 |
| 洞身 | 变形、裂缝、渗水、剥落、气蚀；输水异常声响；洞壁接缝损坏；闸门关闭后漏水 |
| 出口 | 出流流态；洞口出流浑水；闸门槽气蚀；底板高低不平 |
| 消能设施 | 冲刷、磨损、淘空；下游河床异常冲刷 |

### 3. 溢洪道（进口段/控制段/陡坡消能）

| 部位 | 检查项 |
|---|---|
| 进口段 | 两侧岸坡稳定；堰前进口堵淤；挡墙裂缝、渗漏；周边砌体完整 |
| 控制段 | 溢流面平整、断裂、空蚀；闸墩堰身裂缝；挡水期闸墩/边墙/底板渗水 |
| 陡坡及消能 | 底板变形、裂缝、掀起；反滤排水堵塞/破坏；边墙稳定、墙后渗漏；挑流鼻坎冲蚀、松动、塌陷、裂缝、老化锈蚀；下游岸坡坍塌 |

### 4. 闸门及启闭机

| 设备 | 检查项 |
|---|---|
| 闸门 | 变形、裂纹、锈蚀、焊缝开裂、铆钉/螺栓松动；门槽卡堵、气蚀；止水设备完整；钢丝绳断丝/黄油老化；转动部分润滑；吊点侧轮；螺杆锈蚀弯曲；升降平稳；支承行走/转动灵活；异响；门体振动 |
| 启闭机 | 运转灵活；钢丝绳卷筒固定磨损/松弛；金属结构焊接开裂；齿轮开裂磨损；减速器/制动器/电动机/轴承固定；减速器/轴承/离合器油量/漏油 |

### 5. 高边坡（溢洪道右岸）

| 检查项 |
|---|
| 裂缝开裂；滑坡险情；位移观测；排水设施清理畅通 |

### 6. 其他设备

| 设备 | 检查项 |
|---|---|
| 观测设施/监测仪器 | 完好性 |
| 预警系统 | 运行正常 |
| 备用发电机 | 正常 |
| 通讯/照明设施 | 正常 |
| 防汛物资 | 准备堆放情况 |
| 交通道路 | 维护情况 |

## 二、巡查频次表（排班规则）

| 分类 | 检查项目 | 默认频次 | 加密条件 → 加密频次 |
|---|---|---|---|
| 工程 | 坝体、近坝区、输泄水洞外设施、防汛道路、溢洪道 | **1 次/天** | 节假日/主汛期(7-9月)/高水位 → **2 次/天** |
| 工程 | 库区水面 | 2 次/周 | — |
| 工程 | 高边坡 | **1 次/周** | — |
| 工程 | 工程保护范围内 | 1 次/周 | — |
| 工程 | 库尾管理区 | 2 次/月 | — |
| 机电 | 机电设备 | **1 次/天** | 节假日/主汛期/高水位 → **2 次/天** |

> **加密规则**：高水位、强降雨期间加密溢洪道、高边坡、闸门、启闭机等险工险情易发部位。

## 三、巡查路线（标准动线）

```
下坝路 → 坝顶 → 迎水坡 → 背水坡及坝趾 → 近坝岸坡 → 溢洪道
→ 高/低放水洞 → 高边坡 → 观（监）测设施 → 围网4#门 → 防汛道路
```

机电巡查路线：
```
高放水洞闸室 → 低放水洞检修闸室 → 溢洪道闸室 → 低放水洞工作闸室
→ 防汛专用变压器 → 防汛备用电源 → 通讯及照明设施
```

## 四、检查方法

| 方法 | 工具 |
|---|---|
| 常规 | 眼看、耳听、手摸、鼻嗅、脚踩 + 锤、钎、钢卷尺、放大镜、石蕊试纸 |
| 特殊 | 开挖表层、拆除块石护坡、挖坑、探井、投放化学试剂、潜水员探摸 |
