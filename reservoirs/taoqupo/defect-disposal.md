## 1. 坝肩渗漏

- **症状**：坝肩接触带渗水、浸润线抬高
- **原则**：控制渗漏扩大，防止流土管涌与坡面冲刷
- **步骤**：
  1. 清除渗水出流/浸湿范围地表杂物与软泥，向外扩大 5–10m
  2. 每隔 3–5m 开挖斜向导渗沟（**沟深 80cm，宽 60cm**），与坝体排水沟相连
  3. 就近取砂石混合料装袋，铺筑贴坡式反滤层（**厚度 60cm**，上下叠压密实）
  4. 反滤层范围大于渗流/浸湿坡面 5–10m
  5. 备有土工织物时先铺土工织物，后压砂石袋
  6. 土料+块石补坡固脚，防局部滑坡
- **物资**：编织袋、砂石料、土工织物、块石

---

## 2. 大坝护坡塌陷

- **症状**：上游护坡风浪掏刷/松动脱落/架空坍塌；冰冻鼓胀；下游雨水冲刷雨淋沟
- **原则**：抓紧翻筑抢护，防止险情扩大
- **步骤**：
  1. 风浪掏刷 → 填补翻修；条件允许时翻挖分层填土夯实，按垫层+护坡恢复
  2. 冰冻 → 加厚砌石护坡反滤垫层、涂黑混凝土板、铺保温板
  3. 雨水冲刷 → 削坡、开挖回填，做好坝面排水沟
- **物资**：块石、砂石垫层、土料、保温板

---

## 3. 大坝滑坡

- **症状（滑坡三联征）**：
  - 坝体短时间持续显著位移，裂缝连续性位移且逐渐加大
  - **边坡下部水平位移 > 上部**；**上部垂直位移向下，下部向上**
  - 滑动主裂缝两端向边坡下部弯曲，主缝上下侧有错动
- **原则**：**下部压重，上部减载**
- **步骤**：
  1. 塑料薄膜/土工膜覆盖封闭滑坡裂缝；裂缝上方开挖截水沟拦截雨水
  2. 高水位/渗漏引起下游滑坡 → 防渗处理 + 下游排水反滤
  3. 小滑坡体 → 全部挖除，原土料分层回填夯实
  4. 大滑坡体 → 松土挖除，原土料分层回填夯实
  5. 陡边坡 → 放缓坝坡，排水体接至新坝脚
  6. 滑坡体底部前缘滑出 → 砌石固脚或抛石压脚（镇压台/压坡体）
  7. 风浪掏刷上游滑坡 → 翻挖分层填土夯实 + 防风浪护坡
  8. 地震滑坡 → 开挖回填、放缓坝坡、压重固脚
- **物资**：土工膜、土料、块石、砂石

## 4. 大坝裂缝

- **症状**：横向裂缝（不均匀沉降，可贯穿坝体）、纵向裂缝、非滑坡性中等裂缝
- **原则**：分类分治
- **步骤**：
  1. **横向裂缝**（深度<5m，水面以上/背水坡）→ 开挖回填（深度>裂缝+0.5m，宽 1–2m，超两端 1m），逐层填土夯实
  2. **横向裂缝**（迎水坡水面以下）→ 坝顶"横墙隔断"法：坑槽 3–5m × 1.5–2m，深至缝底+0.5m，壁面挂防渗膜后填土夯实
  3. **横向裂缝**（深度大）→ 降低库水位至裂缝以下，充填灌浆
  4. **纵向裂缝**（较宽较深）→ 开挖回填（深至缝下 0.3–0.5m，底宽≥0.5m，超两端 2m）
  5. **非滑坡中等裂缝** → 上部开挖回填（约 2m）+ 下部预埋灌浆管重力/压力灌浆
- **物资**：土料、防渗膜、灌浆设备

## 5. 土坝集中漏水

- **症状**：漏洞进水口、集中渗流
- **原则**：**上堵下排，临背并举**
- **寻找进水口**：水深浅无风浪时观察水面漩涡；不明显时撒麦麸/谷糠/锯末找漩涡
- **步骤**：
  1. **临水堵洞**：
     - 洞口小、可接近、土质硬 → 软楔/草捆堵塞（圆锥网罩，网格 10cm，内填麦秸/稻草+粘土），小头向洞口塞入，棉被/篷布铺盖，土袋压牢，粘土封堵闭气
     - 洞口大 → 盖堵法：铁锅正/反扣（胶泥封闭）或软帘/篷布重叠数层盖堵
  2. **背水导渗**：反滤压盖 / 透水压渗台（出口小而多）/ 反滤围井（集中大洞）
  3. **降低库水位**：开启泄水洞或溢洪道至渗水进口以下
- **物资**：软楔、草捆、铁锅、软帘、篷布、棉被、土袋、砂石、块石、铅丝、木桩

## 6. 土坝渗水

- **症状**：背水坡大面积渗水
- **原则**：少量清水无发展且水位不涨 → 加强观察暂不处理；严重或浑浊且水位续涨 → 及时抢护
- **步骤（临水截渗）**：
  1. **土工膜截渗**：满铺渗水段边坡并深入坡脚外 1m，搭接>0.5m；卷在 8–10m 滚筒上，下边折成卷筒插 **4–5cm 钢管**加重；铺好后压 1–2 层土/砂石袋
  2. **土袋/柳桩前戗截渗**：临水坡脚外用土袋筑隔墙；或打木桩一排（桩距 1m，入土 1m，顶高出水面 1m），编织柳枝/芦苇篱笆，抛土
  3. **降低库水位**
- **物资**：土工膜、钢管、土袋、木桩、柳枝/芦苇、土料

---

## 7. 管涌、流土

- **症状**：背水坝脚附近地基土沙流失、涌水涌沙、隆起
- **步骤**：
  1. **反滤压盖**（管涌/流土多、面积大、连片）：
     - 土工织物法：清基 → 铺土工织物 → 砂石透水料 → 块石/沙袋
     - 砂石法：清基 → 涌水涌沙严重处抛块石/砖消杀水势 → 粗砂 20cm → 小石子 20cm → 大石子 20cm → 块石保护
  2. **透水压渗台**（范围大、反滤料缺、沙土料丰）：透水性大的沙土修平台，平衡渗压
  3. **流土抢护**（隆起部位）：麦秸/稻草 10–20cm + 柳枝 20–30cm（>30cm 横竖分层），压土袋/块石
  4. **降低库水位**
- **物资**：土工织物、粗砂、石子、块石、沙袋、麦秸、柳枝、土袋

---

## 8. 溢洪泄水建筑物损坏

- **症状**：底板破坏、表面冲刷
- **步骤**：
  1. **降低扬压力**：上游加强防渗，下游改善排水
  2. **表面破坏修护**：水泥速凝砂浆或环氧砂浆修补
- **物资**：水泥速凝砂浆、环氧砂浆

---

## 9. 高边坡滑坡（溢洪道右岸）

- **症状**：裂缝开裂、滑坡险情（泥质页岩软化+雨水入渗）
- **原则**：预防为主，加强监测
- **步骤**：
  1. 裂缝/滑坡险情 → **削坡减载**：3–5 台挖掘机+装载机 + 6–12 辆自卸汽车，从上至下挖土减载
  2. 垮塌但不影响相邻建筑 → 削坡减载 + 清理垮塌土体恢复功能
  3. 滑坡阻塞溢洪道 → 低洞作为主要泄洪（提前开启降低库水位）→ 清除滑塌体抢通溢洪道 → 削坡减载
  4. 建筑物损毁 → 清理土体+拆除损毁闸门保证泄洪 → 削坡减载 → 限制蓄水 → 专项评估 → 恢复重建
- **物资**：挖掘机、装载机、自卸汽车
