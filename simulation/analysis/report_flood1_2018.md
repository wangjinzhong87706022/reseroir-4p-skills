# 2018年第二场次洪水（id=1）预演报告

## 一、场景描述

- 洪水名称：2018年第二场次洪水
- 时段：2018-08-22 09:00 ～ 2018-08-23 08:00（历时23小时）
- 起调水位：458.06m，目标水位：458.06m
- 降雨：场次总降雨 6.08mm（前23小时均匀0.38mm/h，后1小时0）
- 入库过程：入库洪峰 61.41 m³/s，出现在 08-22 09:00（起调时刻，呈单调退水），退至 08-23 08:00 的 0.36 m³/s
- 历史记录：本次为2018年第二次泄洪过程。8月22日9:00开闸（库水位458.06m），8月23日14:00闭闸（库水位457.96m），历时29小时，开闸5道，最大泄洪9.90 m³/s、最小9.75 m³/s，溢洪总量102.74万m³（两次累计5533.26万m³）

## 二、调度方案

- 调度目标：防洪优先（控制最高水位）
- 调度模式：控制最高水位 ≤ 458.06m
- 泄洪方式：开启闸门5道，恒定小流量泄洪（约9.56~10.08 m³/s）
- 约束参数：汛限水位 462.88m（model_config.max_water_level），下游安全泄量 95.1 m³/s，最大泄量 191 m³/s

## 四、结论建议

- 调度效果：采用恒定小流量泄洪（约10 m³/s），库水位由458.06m缓升至458.50m后平稳，全程远低于汛限水位，削峰显著，调度安全有效。
- 风险提示：无超限风险。建议汛前保持同等起调水位空间，后续场次可沿用"小流量恒定泄洪"模式。
- 改进建议：核对 srm_flood_history_result 中 inPeakFlow 与 peakShavingFlowRate 字段口径，避免统计指标误导。

## 五、安全约束校验

最高水位 458.50m，距汛限水位 462.88m 还有 4.38m，未超限；最大下泄 10.08 m³/s，低于下游安全泄量 95.1 m³/s（亦远低于最大泄量 191 m³/s）。

## 六、法规依据

依据《防洪法》第41条，水库汛期调度运用应确保大坝安全并兼顾上下游防洪；依据《三岔水库调度规程》，汛期应优先采用防洪优先方案，汛前控制水位不高于汛限水位。
