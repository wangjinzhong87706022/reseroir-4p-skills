## 一、调度目标与模式

### 调度目标

| 代码 | 名称 | 适用条件 | 优先级 |
|------|------|---------|--------|
| 0 | 防洪优先 | 暴雨预报、高水位、汛期 | 安全 > 兴利 |
| 1 | 兴利供水 | 低水位、枯水期、供水紧张 | 兴利 > 安全 |
| 2 | 综合平衡 | 常规条件、水位适中 | 平衡安全与兴利 |

### 调度模式

| 代码 | 名称 | 说明 | 典型搭配 |
|------|------|------|---------|
| 0 | 控制最高水位 | 水位不超过上限 | 防洪优先 |
| 1 | 控制最低水位 | 水位不低于下限 | 兴利供水 |
| 2 | 控制水位范围 | 水位在上下限之间 | 综合平衡 |
| 3 | 控制最大出库 | 出库流量不超过上限 | 防洪优先 |
| 4 | 控制最小出库 | 出库流量不低于下限 | 兴利供水 |
| 5 | 控制出库范围 | 出库流量在上下限之间 | 综合平衡 |

### 调度目标选择规则（依据规程）

- 当前水位 > 汛限水位 - 2m → **防洪优先**（schedulingTarget=0）
- 当前水位 < 死水位 + 3m → **兴利保供**（schedulingTarget=1）
- 水位适中 → **综合平衡**（schedulingTarget=2）

## 二、降雨与洪水关系

### 降雨量级划分

| 量级 | 24h 降雨量 | 48h 降雨量 | 洪水等级 |
|------|-----------|-----------|---------|
| 小雨 | < 10mm | < 20mm | 无明显洪水 |
| 中雨 | 10-25mm | 20-50mm | 小洪水 |
| 大雨 | 25-50mm | 50-100mm | 中洪水 |
| 暴雨 | 50-100mm | 100-200mm | 大洪水 |
| 大暴雨 | 100-250mm | 200-500mm | 特大洪水 |
| 特大暴雨 | > 250mm | > 500mm | 超标准洪水 |

### 降雨分布模式

| 模式 | 特点 | 适用场景 |
|------|------|---------|
| 均匀分布 | 每小时降雨量相同 | 简单估算、保守计算 |
| 三角分布 | 前期少、中期峰值、后期递减 | 接近典型暴雨过程 |
| 前峰型 | 前期降雨集中 | 需要快速响应 |
| 后峰型 | 后期降雨集中 | 调蓄压力最大 |

## 四、调度效果指标

### 削峰率

```
削峰率 = (入库洪峰 - 出库洪峰) / 入库洪峰 × 100%
```

| 削峰率 | 效果评价 | 说明 |
|--------|---------|------|
| > 40% | 优秀 | 调蓄效果显著 |
| 30-40% | 良好 | 调蓄效果明显 |
| 20-30% | 一般 | 有一定调蓄效果 |
| < 20% | 较差 | 调蓄效果有限 |

### 调蓄量

```
调蓄量 = 总入库水量 - 总出库水量（万m³）
```

调蓄量越大，说明水库拦蓄洪水越多，下游压力越小。

## 五、历史经验参考

### 典型调度策略

| 场景 | 推荐策略 | 理由 |
|------|---------|------|
| 暴雨预报 + 高水位 | 防洪优先 + 控制最高水位 | 安全第一 |
| 持续降雨 + 中水位 | 综合平衡 + 控制水位范围 | 兼顾安全和蓄水 |
| 短时暴雨 + 低水位 | 防洪优先 + 控制最大出库 | 快速泄洪 |
| 旱季 + 低水位 | 兴利 + 控制最低水位 | 保障供水 |

### 常见失败原因

1. **起调水位过高**：未提前预泄，导致洪水来临时无调蓄空间
2. **调度时长不足**：计算时长短于实际洪水过程，后期失控
3. **下泄流量过大**：超过下游安全泄量，造成下游洪灾
4. **未考虑后续降雨**：仅根据当前降雨调度，未考虑预报

## 七、法律法规依据

- 《中华人民共和国防洪法》第41条：汛期水库不得擅自在汛限水位以上蓄水
- 《水库大坝安全管理条例》第17条：汛期必须执行批准的调度方案
- 《水库调度规程编制导则》SL 224-2019：调度规则制定方法
