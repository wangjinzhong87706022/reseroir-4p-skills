## 使用方法

```
用户问题："当前水位超汛限了，怎么办？"

Agent 判断：
  - 关键词："超汛限" → 触发应急响应
  - 关键词："怎么办" → 需要具体措施

Agent 操作：
  1. 读取 references/emergency-response.md
  2. 找到"水位超限应急响应"章节
  3. 结合当前水位数据，给出具体建议
```

## 注意事项

1. **先读再答**：遇到上述场景，先读取对应文件，不要凭记忆回答
2. **数据验证**：知识库中的数值（如汛限水位）需与数据库实际值交叉验证
3. **时效性**：法律法规和标准可能更新，以最新版本为准
4. **结合实际**：知识库提供通用规则，具体决策需结合当前水位、气象等实时数据
