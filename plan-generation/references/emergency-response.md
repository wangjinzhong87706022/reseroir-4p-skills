# 应急响应知识库

> **用途**：Agent 处理紧急情况时的响应依据
> **触发场景**：Q35-Q39（应急响应类问题）
> **引用方式**：回答中引用本文件时请注明"根据应急响应规程"

---

## 一、水位超限应急响应

### 1.1 水位超汛限水位

```
触发条件：实时水位 > 汛限水位（462.5m）

应急措施：
  ① 立即加大泄洪，全力降低水位
  ② 通知防汛值班人员
  ③ 加密水位监测频率（每15分钟一次）
  ④ 启动防洪预案
  ⑤ 通知下游相关单位

调度要求：
  - 下泄流量 = min(最大泄流能力, 下游安全泄量)
  - 目标：尽快将水位降至汛限以下
```

### 1.2 水位超设计洪水位

```
触发条件：实时水位 > 设计洪水位（461.96m）

应急措施：
  ① 全力泄洪，控制水位不超过校核洪水位
  ② 通知上级防汛指挥部
  ③ 启动应急响应
  ④ 准备人员转移方案
  ⑤ 每小时向上级报告水情
```

### 1.3 水位超校核洪水位

```
触发条件：实时水位 > 校核洪水位（462.88m）

应急措施：
  ① 最大能力泄洪
  ② 立即通知防汛指挥部
  ③ 启动一级应急响应
  ④ 执行人员转移方案
  ⑤ 做好大坝抢险准备
```

## 二、气象预警应急响应

### 2.1 暴雨红色预警

```
响应措施：
  ① 提前预泄，降低水位至汛限以下2m
  ② 加密监测频率（每30分钟）
  ③ 通知所有防汛责任人到岗
  ④ 准备应急物资
  ⑤ 通知下游做好准备
```

### 2.2 暴雨橙色预警

```
响应措施：
  ① 提前预泄，降低水位至汛限以下1m
  ② 加密监测频率（每1小时）
  ③ 通知主要防汛责任人
  ④ 检查应急物资
```

### 2.3 暴雨黄色预警

```
响应措施：
  ① 关注天气变化
  ② 适当预泄，预留防洪库容
  ③ 通知值班人员加强巡查
```

## 三、设备故障应急响应

### 3.1 闸门故障

```
响应措施：
  ① 确认故障闸门数量和位置
  ② 评估剩余泄洪能力
  ③ 调整调度方案，使用可用闸门
  ④ 通知维修人员
  ⑤ 如泄洪能力严重不足，降低水位运行
```

### 3.2 水情测报系统故障

```
响应措施：
  ① 启用人工观测
  ② 增加人工观测频次
  ③ 通知运维人员修复
  ④ 调度决策参考最近有效数据
  ⑤ 保守调度，预留更大安全余量
```

## 四、下游险情联动

### 4.1 下游河道管涌/漫堤

```
响应措施：
  ① 立即减少下泄流量
  ② 下泄流量 ≤ min(安全泄量的50%, 当前入库流量的50%)
  ③ 适当拦蓄洪水
  ④ 密切关注水库水位变化
  ⑤ 如水位持续上涨，需权衡上下游风险
```

### 4.2 下游城市内涝

```
响应措施：
  ① 减少下泄流量
  ② 错峰调度：等下游洪峰过后再加大泄洪
  ③ 通知下游做好排涝准备
```

---

## 五、连续降雨应对

### 5.1 多日连续降雨

```
应对策略：
  ① 提前预泄，预留足够防洪库容
  ② 调度时长覆盖整个降雨过程
  ③ 分阶段调度：
     - 降雨初期：适度预泄
     - 降雨中期：加大泄洪
     - 降雨后期：逐步减少泄洪
  ④ 密切关注水位变化趋势
```

### 5.2 间歇性降雨

```
应对策略：
  ① 在降雨间歇期预泄
  ② 为下一轮降雨预留库容
  ③ 动态调整调度方案
```

## 六、应急响应流程

```
发现异常
  ↓
判断类型（水位超限/气象预警/设备故障/下游险情）
  ↓
确定响应等级（Ⅰ级/Ⅱ级/Ⅲ级/Ⅳ级）
  ↓
启动相应预案
  ↓
通知相关人员
  ↓
执行应急措施
  ↓
持续监测
  ↓
评估效果
  ↓
调整措施 或 终止响应
```
