## 一、法律法规

### 1.1 《中华人民共和国防洪法》（2016年修正）

**核心条款**：

| 条款 | 内容 | 对预案的意义 |
|------|------|-------------|
| 第38条 | 防洪方案由防汛指挥机构制定和执行 | 预案必须由防汛指挥机构审批 |
| 第40条 | 水库管理单位必须执行经批准的调度方案 | 预案一旦批准必须执行，不可擅自更改 |
| 第41条 | 汛期水库不得擅自在汛限水位以上蓄水 | 汛限水位是硬约束 |
| 第44条 | 洪水预报由水文机构发布 | 预案的降雨/洪水数据来源必须权威 |
| 第45条 | 紧急防汛期可采取非常措施 | 紧急预案可突破常规约束 |

**对 Skill 的约束**：
- 预案参数不能超过经批准的汛限水位
- 预案必须明确调度权限（谁批准、谁执行）
- 紧急情况需有特殊处理路径

### 1.2 《水库大坝安全管理条例》（2011年修订）

**核心条款**：

| 条款 | 内容 | 对预案的意义 |
|------|------|-------------|
| 第16条 | 大坝必须定期安全鉴定 | 预案参数基于大坝安全鉴定结果 |
| 第17条 | 汛期必须执行批准的调度方案 | 预案不可突破安全鉴定确定的参数 |
| 第20条 | 发现险情必须立即报告并采取措施 | 预案需包含险情应急响应 |
| 第23条 | 不得擅自改变大坝功能 | 预案不能改变水库设计用途 |

**关键参数来源**：
- 校核洪水位 → 大坝安全鉴定报告
- 设计洪水位 → 大坝安全鉴定报告
- 最大泄流能力 → 工程设计文件

## 二、国家标准（GB）

### 2.1 GB 17621-1998《大中型水电站水库调度规范》

**适用范围**：大中型水电站水库

**核心内容**：

| 章节 | 内容 | 对预案的指导 |
|------|------|-------------|
| 3.1 | 调度基本原则 | 安全第一、统筹兼顾 |
| 3.2 | 防洪调度 | 汛限水位控制、洪水调度规则 |
| 3.3 | 兴利调度 | 供水、灌溉、发电目标 |
| 3.4 | 综合利用调度 | 多目标协调 |
| 4 | 调度图 | 防洪调度图、兴利调度图的绘制方法 |
| 5 | 调度方案编制 | 预案编制的基本要求 |

**防洪调度规则**：
```
正常调度：水位 < 汛限水位 → 按兴利需要调度
非常调度：水位 ≥ 汛限水位 → 加大泄量，控制水位不超过汛限
紧急调度：水位 ≥ 设计洪水位 → 全力泄洪，确保大坝安全
```

### 2.2 GB/T 50587-2018《水库调度设计规范》

**适用范围**：新建、扩建、加固水库的调度设计

**核心内容**：

| 章节 | 内容 |
|------|------|
| 3 | 基本资料（水文、工程、社会经济） |
| 4 | 防洪调度设计（调度方式、调度规则、调度图） |
| 5 | 兴利调度设计（供水、灌溉、发电） |
| 6 | 生态调度设计（生态流量保障） |
| 7 | 调度方案比选 |

**防洪调度方式**：
- **补偿调度**：下游无防洪要求时，水库按自身安全调度
- **错峰调度**：水库泄洪与下游洪峰错开
- **拦洪调度**：水库拦蓄洪水，削减下游洪峰

### 2.3 GB/T 50138-2010《水位观测标准》

**对预案的意义**：水位观测精度直接影响预案参数的准确性

| 水位等级 | 观测精度要求 |
|----------|-------------|
| 大型水库 | ±1cm |
| 中型水库 | ±2cm |
| 小型水库 | ±5cm |

### 3.3 SL 104-2015《水利工程水利计算规范》

**对预案的意义**：规范了水利计算方法

| 计算内容 | 方法 |
|----------|------|
| 洪水演进 | 水文学方法（马斯京根法等） |
| 水位-库容关系 | 实测数据插值 |
| 泄流能力计算 | 水力学公式 |
| 调洪演算 | 水量平衡法 |

**调洪演算基本公式**：
```
水量平衡方程：
  I - O = dS/dt

其中：
  I = 入库流量（来自水文预报）
  O = 出库流量（由泄流建筑物和水位决定）
  S = 蓄水量（由水位-库容关系确定）
  t = 时间
```

## 四、调度规则知识

### 4.1 防洪调度规则

#### 规则1：基于水位的分级调度

```
IF 水位 < 汛限水位:
    正常调度，按兴利需要控制
ELIF 汛限水位 ≤ 水位 < 设计洪水位:
    加大泄量，控制水位不超过设计洪水位
ELIF 设计洪水位 ≤ 水位 < 校核洪水位:
    全力泄洪，控制水位不超过校核洪水位
ELIF 水位 ≥ 校核洪水位:
    紧急调度，确保大坝安全
```

#### 规则2：基于入库流量的调度

```
IF 入库流量 < 安全泄量:
    出库流量 = 入库流量（维持水位不变）
ELIF 安全泄量 ≤ 入库流量 < 最大泄流能力:
    出库流量 = 安全泄量（限制下泄，拦蓄洪水）
ELIF 入库流量 ≥ 最大泄流能力:
    出库流量 = 最大泄流能力（全力泄洪）
```

#### 规则3：基于预报的预泄调度

```
IF 预报未来N小时降雨 > 阈值:
    提前预泄，降低水位至汛限以下
    预泄量 = 预报降雨量 × 流域面积 × 径流系数
    预泄流量 = 预泄量 / 预泄时间
```

### 4.2 兴利调度规则

#### 规则1：供水优先

```
IF 水位 > 死水位:
    按供水需求下泄
ELIF 水位 = 死水位:
    停止供水，保障生态基流
```

#### 规则2：灌溉调度

```
IF 灌溉季节 AND 水位 > 灌溉限制水位:
    按灌溉需水量下泄
ELSE:
    减少下泄，蓄水保供
```

### 4.3 综合利用调度规则

```
优先级排序：
1. 大坝安全（最高优先级）
2. 防洪安全
3. 供水安全
4. 灌溉需求
5. 发电需求
6. 生态需求
7. 航运需求（最低优先级）
```

## 五、关键参数确定方法

### 5.1 汛限水位确定

**方法1：基于防洪库容法**
```
汛限水位 = 对应防洪库容的水位
防洪库容 = 设计洪水总量 / (1 - 泄流比)
```

**方法2：基于调洪演算法**
```
假定不同汛限水位 → 调洪演算 → 确定满足防洪要求的最低汛限水位
```

**方法3：分期汛限水位**
```
前汛期：汛限水位较低（预留更多防洪库容）
主汛期：汛限水位最低（防洪压力最大）
后汛期：汛限水位逐步抬高（逐步回蓄）
```

### 5.2 最大泄流能力确定

**开敞式溢洪道**：
```
Q = C × B × H^(3/2)

其中：
  C = 流量系数（取决于堰型）
  B = 堰顶宽度（m）
  H = 堰上水头（m）
```

**闸控式溢洪道**：
```
Q = μ × A × √(2gH)

其中：
  μ = 流量系数
  A = 闸门过流面积（m²）
  g = 重力加速度（9.81 m/s²）
  H = 闸前水头（m）
```

### 5.3 安全泄量确定

```
安全泄量 = min(河道安全泄量, 闸门最大泄流能力, 下游承泄能力)

其中：
  河道安全泄量 = 河道设计流量（由河道断面和堤防高程决定）
  闸门最大泄流能力 = 由闸门尺寸和水头决定
  下游承泄能力 = 下游河道和堤防的承载能力
```

## 六、预警指标体系

### 6.1 水位预警指标

| 预警等级 | 水位范围 | 响应措施 |
|---------|---------|---------|
| 蓝色（关注） | 汛限水位 - 1m ≤ 水位 < 汛限水位 | 加密监测频率 |
| 黄色（警戒） | 汛限水位 ≤ 水位 < 设计洪水位 | 启动防洪预案 |
| 橙色（严重） | 设计洪水位 ≤ 水位 < 校核洪水位 | 紧急调度+人员转移 |
| 红色（特别严重） | 水位 ≥ 校核洪水位 | 全力泄洪+紧急撤离 |

### 6.2 降雨预警指标

| 预警等级 | 降雨量（24h） | 响应措施 |
|---------|-------------|---------|
| 蓝色 | 25-50mm | 关注天气变化 |
| 黄色 | 50-100mm | 启动防洪预案 |
| 橙色 | 100-250mm | 紧急调度 |
| 红色 | > 250mm | 全力防洪 |

### 6.3 流量预警指标

| 预警等级 | 入库流量 | 响应措施 |
|---------|---------|---------|
| 蓝色 | < 安全泄量的 50% | 正常调度 |
| 黄色 | 安全泄量的 50%-80% | 加大泄量 |
| 橙色 | 安全泄量的 80%-100% | 限制泄量 |
| 红色 | > 安全泄量 | 全力泄洪 |

## 七、调度方案模板

### 7.1 防洪调度方案模板

```markdown
# 防洪调度方案

## 一、基本情况
- 水库名称：XXX
- 总库容：XXX 万m³
- 防洪库容：XXX 万m³
- 汛限水位：XXX m
- 设计洪水位：XXX m
- 校核洪水位：XXX m

## 二、调度目标
- 确保大坝安全
- 削减下游洪峰
- 保障下游保护区安全

## 三、调度规则
### 3.1 正常调度（水位 < 汛限水位）
- 按兴利需要控制下泄流量
- 下泄流量 ≤ 安全泄量

### 3.2 非常调度（汛限水位 ≤ 水位 < 设计洪水位）
- 加大泄量，控制水位不超过设计洪水位
- 下泄流量 ≤ 最大泄流能力

### 3.3 紧急调度（水位 ≥ 设计洪水位）
- 全力泄洪，确保大坝安全
- 启动应急预案

## 四、预警指标
- 蓝色预警：水位 ≥ 汛限水位 - 1m
- 黄色预警：水位 ≥ 汛限水位
- 橙色预警：水位 ≥ 设计洪水位
- 红色预警：水位 ≥ 校核洪水位

## 五、应急措施
- 人员转移方案
- 物资调配方案
- 通讯保障方案
```
