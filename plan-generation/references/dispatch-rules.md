# 水库调度规则知识库

> **用途**：Agent 推荐调度参数时的规则依据
> **触发场景**：Q24(调度目标选择)、Q25(调度时长)、Q27(目标水位)、Q40(汛期首场洪水)
> **引用方式**：回答中引用本文件时请注明"根据调度规则"或"依据规程"

---

## 一、调度目标选择规则

### 规则1：基于水位的调度目标选择

```
IF 当前水位 > 汛限水位 - 2m:
    → 防洪优先（schedulingTarget=0）
    理由：水位偏高，需预留防洪库容

ELIF 当前水位 < 死水位 + 3m:
    → 兴利保供（schedulingTarget=1）
    理由：水位偏低，需蓄水保供水

ELSE:
    → 综合平衡（schedulingTarget=2）
    理由：水位适中，兼顾防洪和兴利
```

### 规则2：基于气象条件的调度目标选择

```
IF 暴雨红色/橙色预警:
    → 防洪优先
ELIF 暴雨黄色预警:
    → 防洪优先 或 综合平衡（视水位而定）
ELIF 无降雨预报 且 水位偏低:
    → 兴利保供
ELIF 常规天气:
    → 综合平衡
```

### 规则3：基于汛期的调度目标选择

```
IF 主汛期（7-8月）:
    → 默认防洪优先
ELIF 前汛期（5-6月）:
    → 根据气象条件选择
ELIF 后汛期（9-10月）:
    → 逐步转向兴利蓄水
ELIF 非汛期（11-4月）:
    → 兴利保供为主
```

## 二、调度模式选择规则

| 模式值 | 名称 | 适用场景 |
|--------|------|---------|
| 0 | 控制最高水位 | 防洪场景：确保水位不超过上限 |
| 1 | 控制最低水位 | 兴利场景：确保水位不低于下限 |
| 2 | 控制水位范围 | 综合场景：水位在指定范围内波动 |
| 3 | 控制最大出库流量 | 下游防洪：限制下泄保护下游 |
| 4 | 控制最小出库流量 | 保供水：确保最小下泄量 |
| 5 | 控制出库流量范围 | 综合控制：流量在指定范围内 |

### 选择规则

```
IF 防洪优先:
    schedulingModel = 0（控制最高水位）
    或 schedulingModel = 3（控制最大出库，当下游有防洪要求时）

IF 兴利保供:
    schedulingModel = 1（控制最低水位）
    或 schedulingModel = 4（控制最小出库，当需要保证供水时）

IF 综合平衡:
    schedulingModel = 2（控制水位范围）
    或 schedulingModel = 5（控制出库流量范围）
```

## 三、目标水位确定规则

### 规则1：防洪优先的目标水位

```
目标水位 = 汛限水位 - 安全余量

安全余量确定：
  - 暴雨蓝色预警：0.3m
  - 暴雨黄色预警：0.5m
  - 暴雨橙色预警：1.0m
  - 暴雨红色预警：2.0m
  - 无预警：0.2m
```

### 规则2：兴利保供的目标水位

```
目标水位 = min(正常蓄水位, 当前水位 + 蓄水需求)

蓄水需求：
  - 供水紧张：+3m
  - 一般需求：+1m
  - 充足：维持当前
```

### 规则3：综合平衡的目标水位

```
目标水位 = (汛限水位 + 死水位) / 2
或
目标水位 = 当前水位（维持现状）
```

## 四、调度时长选择规则

```
IF 短时强降雨（<6h）:
    tmSpan = 6h

ELIF 一般降雨（6-24h）:
    tmSpan = 24h

ELIF 持续降雨（24-48h）:
    tmSpan = 48h

ELIF 长历时降雨（>48h）:
    tmSpan = 72h

ELIF 无降雨:
    tmSpan = 24h（常规调度）
```

---

## 五、安全泄量约束规则

```
实际下泄流量 = min(
    调度计算的出库流量,
    配置的最大下泄能力,
    下游安全泄量,
    当前水位对应的泄流能力
)

IF 入库流量 > 安全泄量:
    需要拦蓄的水量 = (入库流量 - 安全泄量) × 时间
    评估水库是否有足够的防洪库容
    IF 库容不足:
        → 提示风险，可能需要启用非常规措施
```

## 六、紧急调度规则

```
IF 水位 ≥ 校核洪水位:
    → 紧急调度：全力泄洪，确保大坝安全
    → 通知防汛指挥部
    → 启动人员转移方案

IF 水位 ≥ 设计洪水位:
    → 加大泄洪，控制水位不超过校核洪水位
    → 通知上级主管部门

IF 水位 ≥ 汛限水位:
    → 加大泄洪，控制水位不超过设计洪水位
    → 启动防洪预案
```

---

## 七、调度优先级

```
优先级从高到低：
1. 大坝安全（最高优先级，不可妥协）
2. 下游防洪安全
3. 供水安全
4. 灌溉需求
5. 发电效益
6. 生态流量
7. 其他综合利用
```
