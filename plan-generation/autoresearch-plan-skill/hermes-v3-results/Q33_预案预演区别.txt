     好的，wiki 里没有专门讨论这两个概念的区别。结合水利专业领域和你的          
     plan-generation skill 的实际应用场景，我来梳理一下：                       
                                                                                
     ================================================================           
     预案 vs 预演 — 核心区别                                                    
     ================================================================           
                                                                                
     一、定义                                                                   
                                                                                
       预案（应急预案 / 调度预案）                                              
       ──────────────────────                                                   
       是一份"计划文档"，提前写好的应对方案。                                   
       核心问题是：如果发生了XX情况，我们该怎么做？                             
       例如：你的 plan-generation skill 生成的就是预案 ——                       
       给定当前水位、降雨预报，输出三组调度方案（防洪/综合/兴利），             
       包含调度目标、目标水位、最大下泄、安全泄量等参数。                       
                                                                                
       预演（演练 / 桌面推演 / 实战演练）                                       
       ──────────────────────                                                   
       是一次"模拟行动"，按照预案走一遍流程。                                   
       核心问题是：如果现在真的发生了，我们的预案能跑通吗？                     
       例如：模拟三岔水库水位突涨到463.0m，各部门按预案分工操作，               
       看看通信链路是否畅通、人员能否到位、决策流程是否合理。                   
                                                                                
     二、关键区别                                                               
                                                                                
       维度        预案                    预演                                 
       ─────       ─────                   ─────                                
       本质        文档/计划                行动/过程                           
       产出物      方案文本、参数表          演练记录、评估报告                 
       参与者      主要是方案编制人员        多部门、多角色联动                 
       环境        纸上/系统里              桌面推演或实地演练                  
       验证目标    方案是否合理、合规        流程是否跑得通、人是否到位         
       频率        预案编制后相对固定        定期演练（如每年汛前）             
       时效性      有有效期，需定期修订      每次演练产生新的改进项             
                                                                                
     三、什么情况下用什么？                                                     
                                                                                
       用【预案】的场景：                                                       
       • 汛期前编制水库调度预案（你的 skill 主要干这个）                        
       • 制定突发事件应急处置方案                                               
       • 给上级部门报批审批                                                     
       • 日常决策参考 —— 比如水位涨到什么程度该泄洪、泄多少                     
                                                                                
       用【预演】的场景：                                                       
       • 汛前组织防汛演练，检验预案可操作性                                     
       • 新预案编制后，通过桌面推演验证合理性                                   
       • 人员变动后，让新人熟悉应急流程                                         
       • 重大活动/节假日前，做一次应急拉练                                      
                                                                                
     四、两者的关系                                                             
                                                                                
       预案是预演的依据  →  没有预案，预演就没有"剧本"                          
       预演是预案的检验  →  没有预演，预案可能只是"纸上谈兵"                    
                                                                                
       最佳实践：预案编制 → 桌面预演发现问题 → 修订预案 → 实战预演确认 →        
     定期循环                                                                   
                                                                                
     五、你的系统对应                                                           
                                                                                
       你的 plan-generation skill 做的是"预案"侧：                              
       收集水情数据 → 分析形势 → 生成调度方案 → 对比推荐                        
                                                                                
       如果要做"预演"侧，需要的是：                                             
       模拟场景设定 → 按预案执行调度 → 记录各节点响应 → 评估效果 →              
     输出改进项                                                                 
                                                                                
       目前系统支持了预案生成和预案解读，预演功能（场景模拟、效果评估）         
       可能是后续可以扩展的方向。
