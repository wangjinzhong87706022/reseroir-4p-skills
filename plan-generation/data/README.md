## 四、历史洪水场景设计（5 条）

### 场景矩阵

| ID | 名称 | 历时 | 总降雨 | 雨型 | 起调水位 | 量级 |
|----|------|------|--------|------|---------|------|

### 各场景设计说明

#### 场景17：典型暴雨洪水（24h/266mm）

```
降雨过程：
  0-3h:   5→8→15 mm/h（小到中雨，逐渐加大）
  3-7h:   25→35→42→38 mm/h（大到暴雨，主雨峰）
  7-12h:  30→22→15→10→8 mm/h（逐渐减弱）
  12-24h: 5→3→2→2→1→1→0 mm/h（尾部小雨）

设计意图：典型的南方暴雨洪水，雨峰集中，考验水库拦洪削峰能力。
```

#### 场景18：长历时洪水（48h/284mm）

```
降雨过程：
  0-12h:  3→5→8→10→12→15→18→20→22→25→28→30 mm/h（缓慢加大）
  12-24h: 28→25→22→20→18→15→12→10→8→6→5→4 mm/h（缓慢减小）
  24-48h: 3→3→2→2→2→1→1→1→0→... mm/h（尾部长历时小雨）

设计意图：考验水库长时间调度能力和蓄水能力。
```

#### 场景19：短时特大暴雨（12h/180mm）

```
降雨过程：
  0-2h:   5→15 mm/h（快速加大）
  2-6h:   35→55→45→25 mm/h（极端强度，55mm/h）
  6-12h:  15→8→5→3→2→1 mm/h（快速减弱）

设计意图：极端天气事件，考验水库防洪极限能力。
```

#### 场景20：常规汛期洪水（24h/60mm）

```
降雨过程：
  全程2-5 mm/h均匀分布

设计意图：小洪水，验证常规调度能力，作为基准参考。
```

#### 场景21：复式洪水（36h/200mm）

```
降雨过程：
  第一轮（0-9h）：2→5→10→20→30→25→15→8→5 mm/h
  间歇期（9-12h）：3→2→2 mm/h
  第二轮（12-21h）：3→5→10→18→25→20→12→8→5 mm/h
  尾部（21-36h）：3→2→1→0→... mm/h

设计意图：双峰洪水，考验调度的灵活性——需要在两个洪峰之间调整闸门。
```

## 六、对预案 Skill 的作用

### 6.1 参数推荐参考

Agent 查询历史预案时，可以获取：
- 起调水位 461m 时 → 历史上用 maxWaterLevel=462.88 成功过
- 起调水位 453m 时 → 历史上用 schedulingTarget=1（兴利）
- 短时强降雨 → 历史上用 6h 调度时长

### 6.2 策略选择依据

```
分析历史预案策略分布：
  防洪优先(target=0)：6次，起调水位 460~462m
  兴利供水(target=1)：2次，起调水位 453~454m
  综合调度(target=2)：2次，起调水位 458~460m

Agent 学到的规律：
  "起调水位>460m → 防洪优先"
  "起调水位<455m → 兴利保供"
  "中间水位 → 综合调度"
```

### 6.3 边界条件校验

```
历史参数范围：
  maxWaterLevel：458.0 ~ 462.88m
  maxDrainageCapacity：50 ~ 192 m³/s
  safeDrainageCapacity：50 ~ 95.1 m³/s
  tmSpan：6 ~ 72h

Agent 推荐参数超出范围时 → 标注警告
```

### 6.4 历史洪水预演参考

5 条覆盖不同量级和雨型的洪水场景，可用于：
- 虚拟场景构建的模板
- 敏感性分析的基准
- 调度方案效果验证
