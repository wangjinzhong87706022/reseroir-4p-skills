## 一、基础查询类（Easy）

### Q1: 当前水位查询
**问题**: 三岔水库当前水位是多少？
**预期答案**: 当前水位约 459.18m（查询 st_rsvr_r 最新记录）
**验证 SQL**: `SELECT rz, tm FROM st_rsvr_r WHERE rz IS NOT NULL ORDER BY tm DESC LIMIT 1`

### Q2: 汛限水位查询
**问题**: 三岔水库当前的汛限水位是多少？
**预期答案**: 汛限水位 462.500m（查询 att_res_base 的 fl_low_lim_lev 字段）
**验证 SQL**: `SELECT fl_low_lim_lev, norm_wat_lev FROM att_res_base WHERE res_name='三岔水库'`

### Q3: 水位约束配置
**问题**: 系统配置的最高允许水位和最低允许水位分别是多少？
**预期答案**: 最高 462.88m，最低 446m / 451m（存在两组配置）
**验证 SQL**: `SELECT config_key, value FROM model_config WHERE config_key IN ('max_water_level','min_water_level')`

### Q4: 降雨预报查询
**问题**: 未来24小时的降雨预报情况如何？
**预期答案**: 查询 f_rnfl_h 表，当前预报以晴天/多云为主，降水量为 0
**验证 SQL**: `SELECT ymdh, rn, text FROM f_rnfl_h WHERE ymdh >= NOW() AND ymdh <= DATE_ADD(NOW(), INTERVAL 24 HOUR) ORDER BY ymdh`

### Q5: 气象预警查询
**问题**: 当前有哪些活跃的气象预警？
**预期答案**: 查询 weather_warn 表，有大风蓝色预警、雷电黄色预警等
**验证 SQL**: `SELECT docabstract, docpubtime FROM weather_warn WHERE warn_status='1' ORDER BY docpubtime DESC LIMIT 5`

## 二、数据分析类（Medium）

### Q6: 水位与汛限水位的距离
**问题**: 当前水位距离汛限水位还有多少米？是否安全？
**预期答案**: 462.50 - 459.18 = 3.32m，安全余量充足
**涉及查询**: 同时查 st_rsvr_r 和 att_res_base

### Q7: 水位趋势分析
**问题**: 过去24小时水位是上涨还是下降？变化速率是多少？
**预期答案**: 查询 st_rsvr_r 最近24h数据，计算变化趋势
**验证 SQL**: `SELECT rz, tm FROM st_rsvr_r WHERE rz IS NOT NULL AND tm >= DATE_SUB(NOW(), INTERVAL 24 HOUR) ORDER BY tm`

### Q8: 近期降雨统计

**预期答案**: 查询 st_pptn_r 求和
**验证 SQL**: `SELECT SUM(p) as total_rain FROM st_pptn_r WHERE tm >= DATE_SUB(NOW(), INTERVAL 7 DAY)`

### Q9: 水位-库容关系

**预期答案**: 查询 att_res_stag_cap_disc 插值

### Q10: 泄流能力查询

### Q11: 历史预案统计

## 三、预案生成类（Hard）

### Q13: 防洪优先预案生成
**问题**: 假设未来48小时有暴雨（预计降雨100mm），请以防洪优先策略生成调度预案。
**预期行为**:
1. 查询当前水位 ~459.18m
2. 查询汛限水位 462.50m
3. 查询最大下泄 191 m³/s
4. 生成防洪优先参数：schedulingTarget=0, schedulingModel=0, maxWaterLevel=462.88
5. 参考历史预案（如 id=717 的"防洪安全场景"）

### Q14: 综合平衡预案生成
**问题**: 当前水位正常，无强降雨预报，请生成一套综合平衡的调度预案。
**预期行为**:
1. 确认当前水位安全（459.18 < 462.50）
2. 确认无暴雨预报
3. 使用 schedulingModel=2（控制水位范围）
4. maxWaterLevel 和 minWaterLevel 在合理范围内

### Q15: 多方案对比
**问题**: 请生成3个不同策略的调度方案（防洪/综合/兴利），并对比它们的削峰率和最高水位。
**预期行为**:
1. 生成3组不同参数
2. 分别查询历史相似方案或调用计算
3. 输出对比表格

### Q16: 基于历史洪水的预案
**问题**: 参考2018年第二场次洪水（id=1）的情况，生成一套应对类似洪水的预案。
**预期行为**:
1. 查询 srm_flood_history_base id=1 的降雨数据
2. 分析洪水特征
3. 基于历史经验生成预案参数

### Q17: 滚动预报预案
**问题**: 生成未来72小时的滚动预报方案。
**预期行为**:
1. 查询未来72h降雨预报
2. 使用调度时长 tmSpan=72
3. 生成滚动预报方案

## 四、异常场景类（Edge Case）

### Q18: 水位数据缺失
**问题**: 如果当前水位数据为 NULL，应该如何处理预案生成？
**预期行为**: 检测到 rz=NULL，提示"当前水位数据不可用，无法生成预案"或使用最近有效值
**测试数据**: st_rsvr_r 中 rz 字段有 NULL 值

### Q19: 水位超汛限
**问题**: 如果当前水位已经超过汛限水位（假设 463.0m > 462.5m），应该如何生成预案？
**预期行为**: 紧急模式，生成最大泄流方案，标注"水位超汛限，需紧急调度"

### Q20: 水位接近死水位
**问题**: 如果当前水位接近死水位（假设 452m，接近 451m），应该如何生成预案？
**预期行为**: 兴利优先模式，减少下泄，保供水

### Q21: 降雨预报为空
**问题**: 如果降雨预报数据表 f_rnfl_h 中没有未来时段的数据，如何处理？
**预期行为**: 提示"无降雨预报数据"，基于当前水位和历史数据生成保守方案

### Q22: 气象预警冲突
**问题**: 同时存在暴雨红色预警和高温预警，如何调整预案策略？
**预期行为**: 优先响应暴雨预警，以防洪为主；高温预警作为辅助参考

### Q23: 配置值不一致
**问题**: model_config 中存在两组 max_water_level（462.88 和 459.22），应该使用哪个？
**预期行为**: 需要判断配置的租户/上下文，或提示配置冲突

### Q24: 历史洪水计算失败
**问题**: srm_flood_history_base 中 id=9 的洪水状态为 3（计算失败），如何处理？
**预期行为**: 跳过该记录，提示"该历史洪水计算失败，无法作为参考"

### Q25: 水位-库容曲线超出范围
**问题**: 如果预报水位为 470m，超出了水位-库容曲线的最大范围（467.99m），如何处理？
**预期行为**: 提示"预报水位超出库容曲线范围"，使用外推或报警

### Q26: 降雨预报时间不连续
**问题**: f_rnfl_h 中存在时间间隔大于1小时的记录（如从14:00直接跳到18:00），如何处理？
**预期行为**: 识别数据缺失，插值补全或提示数据不完整

### Q27: 数据库连接失败
**问题**: 如果数据库连接超时或拒绝访问，skill 应该如何响应？
**预期行为**: 返回明确的错误信息，不返回空结果或崩溃

## 五、复杂推理类（Expert）

### Q28: 汛期判断
**问题**: 当前日期是否在汛期内？如果是，汛限水位是多少？
**预期行为**:
1. 查询 att_res_flse_lim 表
2. 如果当前月份在 flood_season_start 和 flood_season_end 之间，判定为汛期
3. 注意：att_res_flse_lim 本地数据为空，需要使用 att_res_base 的 fl_low_lim_lev

### Q29: 安全泄量约束
**问题**: 如果下游安全泄量为 95.1 m³/s，而入库洪峰为 200 m³/s，应该如何调度？
**预期行为**:
1. 识别约束：下泄不能超过 95.1 m³/s
2. 计算需要拦蓄的水量
3. 评估水库是否有足够的防洪库容
4. 如果库容不足，提示风险

### Q30: 多约束优化
**问题**: 同时满足以下约束：水位不超过462.88m、下泄不超过192 m³/s、下游安全泄量不超过95.1 m³/s，最大削峰率是多少？
**预期行为**:
1. 识别三重约束
2. 计算最保守的下泄量（min(192, 95.1) = 95.1）
3. 基于水位-库容曲线计算调蓄能力
4. 推算削峰率

### Q31: 历史方案效果评估
**问题**: 评估历史预案 id=717（2026-05-20）的调度效果，实际水位变化与预期是否一致？
**预期行为**:
1. 查询预案参数：起调水位 459.81m，最高允许 462.88m
2. 查询对应时段的实测水位 st_rsvr_r
3. 对比预报与实测

### Q32: 跨时段调度
**问题**: 如果需要从当前水位 459.18m 在 24 小时内降至 458m，需要多大的平均下泄流量？
**预期行为**:
1. 查询水位-库容关系：459.18m 对应库容 X，458m 对应库容 Y
2. 需要下泄的水量 = X - Y
3. 平均流量 = 水量 / 24h / 3600s

### Q33: 连续降雨应对
**问题**: 如果未来3天每天降雨30mm（共90mm），当前水位459.18m，预计最高水位会达到多少？
**预期行为**:
1. 计算总降雨量 90mm
2. 估算入库总量 = 90mm × 161.25km² × 径流系数
3. 基于水位-库容关系推算最高水位
4. 判断是否超汛限

### Q34: 预案叠加验证
**问题**: 如果同时执行预案 id=717 的参数和当前的降雨预报，结果会怎样？
**预期行为**:
1. 获取预案参数
2. 叠加当前降雨预报
3. 模拟计算结果
4. 评估是否超约束
