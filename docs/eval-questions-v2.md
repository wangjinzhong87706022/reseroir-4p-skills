# 评测问题集改写建议 v2（2026-09-01）

> 状态：Stage 1 产出物。基于 `docs/eval-question-audit.md` 逐题给出改写建议。
> 治理依据：`docs/superpowers/plans/2026-09-01-eval-question-rewrite.md` §R1–R5。
>
> **本文档只给建议，不回填 YAML。** 回填与试跑见 Stage 2+，需另行授权。

## 改写原则速览

- **R1 关键词全量耦合**：`expected_keywords` 是 AND 硬门。每题必须 co-review：改写后若人话回答可能不再出现原关键词，须标"同步调整"并给出建议词。
- **R2 场景数据 ≠ 路径线索**：水位/雨量/洪水 id/日期/汛限数值是场景数据，一律保留；Phase/Layer/Step/三段式/安全校验段/流程名/skill 名/DAG/场景A-D/escalate 是内部术语，剥离。
- **R3 SUP 元问题豁免**：SUP2/4/6/8/10 为知识型元问题，question 不改（SUP4 关键词高耦合风险单独记录）。
- **R4 文档级改动零效果**：本文档为 Stage 1，验收以"逐题有结论 + 关键词复核齐全"为准；对判分的影响在 Stage 2 试跑量化。
- **R5 基线断裂标记**：凡 question 改写的题，Stage 2 回填时 YAML 须加 `question_v2: true` 标记，以便与 8/25 基线区分。

## 逐题格式

```
### <id>  [档位]
- 原 question: "..."
- expected_keywords: [...]
- 建议 question: "..."   （A/豁免标"保留"）
- 改了什么: ...
- 关键词复核: 保留 / 同步调整→[...]
```
