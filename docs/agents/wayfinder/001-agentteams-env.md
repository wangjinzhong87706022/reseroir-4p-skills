## 解决方式

HITL（需要你配合）：
1. 你在服务器上执行 `docker ps | grep hiclaw` 确认 manager 是否在运行
2. 访问 Element Web (`http://127.0.0.1:18088`) 确认是否正常
3. 在 manager 房间尝试发送一条简单消息看是否响应
4. 如果失败，记录具体错误信息（截图或错误日志）
