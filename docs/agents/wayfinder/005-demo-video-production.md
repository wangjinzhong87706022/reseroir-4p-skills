# Ticket 005 — Demo 视频录制方案

## Question

视频是评委唯一看到的"证据"。如何用最低成本录制一段有竞争力的 Demo 视频（5-10分钟）？

## 关键约束

- 一个人录制，没有团队配合
- 需要展示：Matrix 消息流动 + Worker 协作 + 工具网关查询结果
- 视频需要声音/字幕解说，否则评委看不懂

## 录制方案

### 方案A：屏幕录像 + 旁白解说（推荐）
```
工具：OBS Studio（免费）
流程：
1. 录 Element Web Team 房间（展示 Matrix 消息）
2. 录工具网关日志（展示 HTTP 查询）
3. 后期用剪映加上字幕和解说
时长：8-10分钟
成本：0元（OBS免费，剪映免费）
```

### 方案B：分镜动画 + 配音
```
工具：PPT + PowerPoint 录音 + Camtasia
流程：
1. 制作分镜 PPT（展示架构图+协作流程）
2. 录制旁白解说
3. 穿插录屏片段
时长：5-8分钟
成本：需要Camtasia license
```

## 预期答案

**推荐方案A（OBS + 剪映）**：
- OBS 录 Element Web 全屏（展示 Matrix 消息协作）
- 同时开另一个终端显示 `curl` 手动查询工具网关（展示真实数据）
- 后期用剪映加字幕："这是 TeamLeader 调度 water-forecast..."
- 总制作成本：0元，2-3小时

## 视频结构

```
0:00-0:30  开场字幕：水库四预多智能体协作系统
0:30-1:30  系统架构介绍（PPT截图）
1:30-3:30  汛期暴雨场景完整演示（Element Web录屏）
3:30-5:00  工具网关查询日志（展示真实水库数据）
5:00-6:00  TeamLeader 汇总报告（展示最终输出）
6:00-7:00  技术亮点总结（字幕）
```
