# 水位-库容-泄流能力曲线 详解

> 本文档基于《2026年度桃曲坡水库汛期调度运用计划》和《2026年桃曲坡水库防洪抢险应急预案》提取整理。

---

## 一、曲线的定义与关系

### 1.1 三条核心曲线

| 曲线 | 自变量 | 因变量 | 回答的问题 |
|------|--------|--------|-----------|
| **水位-库容曲线** | 水位 (m) | 库容 (万m³) | 这个水位有多少水？ |
| **水位-泄流曲线** | 水位 (m) | 泄量 (m³/s) | 这个水位能泄多少？ |
| **库容-水位曲线** | 库容 (万m³) | 水位 (m) | 库容变化对应水位涨多少？（逆用） |

### 1.2 三条曲线的相互关系

```
┌─────────────────────────────────────────────────────────┐
│                    水库调度计算链                          │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  降雨预报 → 入库流量预报 → 调洪计算                      │
│                                    ↓                     │
│  时段初水位 ──→ 水位-库容曲线 → 时段初库容 V1            │
│                                    ↓                     │
│  时段初水位 ──→ 水位-泄流曲线 → 时段出库流量 Q出          │
│                                    ↓                     │
│  V2 = V1 + (Q入 - Q出) × Δt ──→ 时段末库容              │
│                                    ↓                     │
│  时段末库容 ──→ 库容-水位曲线 → 时段末水位                │
│                                    ↓                     │
│  判断: 最高水位 ≤ 校核洪水位？ → 安全/超限                │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

## 三、曲线形态特征

### 3.1 库容曲线（水位-库容）

```
库容(万m³)
4420 |                        ● 790.5m (校核洪水位)
3949 |                  ● 788.5m (正常蓄水位)
3485 |             ● 786.5m
3250 |        ● 785.5m
2820 |   ● 783.5m (溢洪道堰顶)
   0 |● 762.5m
     +----+----+----+----+----+----+----+----→ 水位(m)
    762  765  768  771  774  777  780  783  786  790
```

**形态特征**：
- 曲线呈 **非线性递增**
- 低水位段（762-770m）：库容增长缓慢，8m水位差仅550万m³（平均69万m³/m）
- 中水位段（770-783m）：库容增长中等，13m水位差约2270万m³（平均175万m³/m）
- 高水位段（783-790.5m）：库容增长较快，7.5m水位差约1600万m³（平均213万m³/m）

**物理含义**：
- 水库为峡谷型，库盆呈狭长形
- 低水位时库容小，水位上涨库容增加慢
- 高水位时淹没面积增大，库容增加加快

### 3.2 泄流曲线（水位-泄量）

```
总泄量(m³/s)
2331 |                        ● 790.5m
1947 |                  ● 789.5m
1507 |            ● 788.5m (正常蓄水位)
1087 |       ● 787.5m
 747 |  ● 786.5m
 447 |    785.5m
 241 |       784.5m
  97 |● 783.5m (堰顶，仅低洞)
     +----+----+----+----+----+----+----+----→ 水位(m)
    783  784  785  786  787  788  789  790
```

**形态特征**：
- **783.5m以下**：仅低洞泄流，恒定为97m³/s（闸门全开）
- **783.5m以上**：溢洪道开始泄流，总泄量 = 溢洪道泄量 + 低洞泄量(97)
- 溢洪道泄量随水位呈 **非线性快速增长**（堰流公式 Q ∝ H^(3/2)）

**分段函数近似**：

| 水位区间 | 溢洪道泄量(m³/s) | 总泄量(m³/s) | 计算公式 |
|---------|----------------|-------------|---------|
| < 783.5m | 0 | 97 | 固定值 |
| 783.5-788.5m | 0 → 1410 | 97 → 1507 | Q = m·B·√(2g)·H^(3/2) |
| 788.5-790.5m | 1410 → 2234 | 1507 → 2331 | 闸门全开，自由泄流 |

### 4.1 实时调度运行

#### 用途1：库容实时计算

```
当前水位 → 查水位-库容表 → 实时库容
```

| 用途 | 示例（桃曲坡） |
|-----|-------------|
| 判断当前蓄水量 | 788.5m → 3949万m³，占兴利库容4290万m³的92% |

### 4.2 洪水调度（核心用途）

#### 用途4：调洪计算

**场景**：遇到洪水，计算最高水位和最大泄量。

**计算流程**：
```
入库洪水过程 → 逐时段试算
  每时段:
    1. 当前水位 → 查水位-库容曲线 → 当前库容V1
    2. 当前水位 → 查泄流曲线 → 当前泄量Q出
    3. 入库流量Q入（已知）
    4. 时段末库容 V2 = V1 + (Q入 - Q出) × Δt
    5. V2 → 查水位-库容曲线 → 时段末水位
  收敛条件: 最高水位 ≤ 校核洪水位790.5m
```

**桃曲坡实际应用**：

| 洪水标准 | 洪峰流量(m³/s) | 起调水位(m) | 最高水位(m) | 最大下泄(m³/s) | 结果 |
|---------|--------------|-----------|------------|--------------|------|
| 5年一遇 | 290 | 788.0 | 788.91 | 100 | ✅ 安全 |
| 10年一遇 | 541 | 788.0 | 788.96 | 200 | ✅ 安全 |
| 20年一遇 | 850 | 788.0 | 788.99 | 330 | ✅ 安全 |
| 30年一遇 | 1060 | 788.0 | 789.02 | 500 | ✅ 安全 |
| 50年一遇 | 1350 | 788.0 | 789.06 | 700 | ✅ 安全 |
| **100年一遇** | **1780** | **788.0** | **788.54** | **1000** | **✅ 安全** |
| **1000年一遇** | **3250** | **788.0** | **790.30** | **993** | **✅ 安全** |

> 所有标准洪水最高水位均不超过790.5m校核洪水位。

**AI应用**：
- 调度优化智能体：自动进行调洪计算 → 生成最优调度方案
- 强化学习：学习不同洪水过程的最优闸门开度序列

#### 用途5：汛限水位控制

**控制逻辑**：
```
水位 < 汛限水位 → 正常蓄水
水位 = 汛限水位 → 开启低洞小流量拉沙泄水(≤100m³/s)
水位 > 汛限水位 → 加大泄量，使水位回落
```

| 9月中旬 | 786.8 | ~3400 | 达汛限 | 停止马栏引水 |

| 10月末 | 785 | ~3250 | 回落 | 次汛期正常蓄水 |

**AI应用**：
- 实时监控水位 → 自动触发预泄/蓄水决策
- 结合天气预报 → 优化预泄时机和流量

## 七、总结

水位-库容-泄流能力曲线是水库调度运行的 **"物理定律"** —— 所有调度决策、风险分析、AI算法都必须基于这三条曲线进行约束和计算。

**核心作用**：
1. **库容计算**：水位→库容转换，实时掌握蓄水状态
2. **泄流决策**：水位→泄量转换，指导闸门操作
3. **水位预报**：库容变化→水位转换，预测未来水位
4. **调洪计算**：逐时段试算，验证调度方案安全性
5. **应急决策**：险情评估、转移决策、溃坝分析
6. **数字孪生**：虚拟水库物理模型的基础
7. **多目标优化**：防洪、兴利、生态、供水的平衡

**在AI智能体中的价值**：
- 四预智能体：核心输入（预报→水位→预警）
- 调度优化智能体：核心约束（调洪计算、方案优化）
- 安全评估智能体：核心参数（水位-安全关系）
- 应急响应智能体：核心依据（险情评估、转移决策）
- 智能巡检智能体：触发条件（高水位巡查）
- 数据治理智能体：基准数据（主数据、校验标准）
