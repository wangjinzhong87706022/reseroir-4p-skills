## 2. 系统性结论

1. **step37 签名族**：09-15 轮已量化"悬置收尾 29/133 vs Qwen 2/133"；本批 5 例是其加重形态——
   从"悬置提问"升级为"虚构权限障碍"（编造表名/模式/约束/凭据缺失）。
2. **运行间波动是 FAIL 面主成分之一**：DV6/EW25/PG3 在 09-15 同模型全 PASS、p2 全 FAIL；
   同款条款 Qwen 133/133 全遵守。单 run 定性不稳，FAIL 例应双 run 聚合后再定性。
3. **可判分的"合规标记行"缺失**：租户声明（DV7）、三域实测引用（EW7）、event 号+链路状态（SUP3）
   ——step37 做了实质分析但省略成句的显式标记；Qwen 有写标记行的习惯。
4. **深度/收敛风格**：DV1 133s vs 1472s、SUP3 155s vs 696s——step37 拿到首个自洽解释即收敛，
   前提冲突后无法用真异常支撑定级。
5. 横切伪影排除：输出前缀 `3\n15`（两跑 41/44 个轨迹均有）为 hermes CLI 产物，与失败无关；
   `answer_extracted=False` 两跑均 ~133/133 常态（回退全量输出判分），非异常。

   前提失真必挂。
