## 一、法律法规

### 1.1 《中华人民共和国防洪法》（2016 修正）

**对预报的意义**：规定洪水预报由水文机构发布，预报/预案数据来源必须权威；汛期水库不得擅自在汛限水位以上蓄水，汛限是硬约束。

**核心原则**（按法律精神，非逐字引述）：

| 原则要求 | 对预报 Skill 的约束 |
|---------|-------------------|
| 防洪方案由防汛指挥机构制定和执行 | 预报结论须能支撑防汛指挥决策 |
| 水库管理单位须执行经批准的调度方案 | 预报参数不能突破经批准的汛限水位 |
| 汛期不得擅自在汛限水位以上蓄水 | 趋势预警阈值须以汛限为基准 |
| 洪水预报由水文机构发布 | 预报数据来源（NMC/水文站）须权威可溯 |
| 紧急防汛期可采取非常措施 | 紧急预报可触发非常规响应路径 |

> 具体条款号（第38/40/41/44/45条等）建议接入《防洪法》全文后核对，本文件暂不固化以免误引。

### 1.2 《水库大坝安全管理条例》（2011 修订）

**对预报的意义**：预案/预报参数基于大坝安全鉴定结果；不得擅自改变大坝功能。

**关键参数来源**：

| 参数 | 来源 |
|------|------|
| 校核洪水位 | 大坝安全鉴定报告 |
| 设计洪水位 | 大坝安全鉴定报告 |
| 最大泄流能力 | 工程设计文件 |

> 预报结论涉及特征水位越限时，须引用安全鉴定确定的设计/校核值（如三岔参考值：汛限 462.50m / 设计 461.96m / 校核 462.88m，**仅参考，实际从 model_config / 工程文件读**）。

### 1.3 《中华人民共和国水法》（2016 修正）

**原则**：开发利用水资源应兼顾上下游、左右岸；调蓄径流应统筹兼顾。预报结论须考虑下游防洪承泄能力。

## 二、国家标准（GB/T）

### 2.1 GB/T 22482《水文情报预报规范》（核心标准）

**这是预报 Skill 最直接的国家标准依据**，规定了预报精度评定、预见期、发布规范。

#### 预报精度评定（合格率 / MAPE）

> 依 GB/T 22482，水文气象预报精度评定采用**合格率**与**误差指标**双轨：

| 评定指标 | 含义 | 本系统映射 |
|---------|------|-----------|
| 合格率 | 预报误差在允许范围内的次数占比 | `forecast_accuracy_record` 聚合 |
| 绝对误差 | 预报值 - 实测值 | `forecast_timeline.bias_mm` |
| 平均绝对误差 MAE | |bias| 的均值 | `forecast_timeline.mae_mm` |
| 平均绝对百分比误差 MAPE | |预报-实测|/实测 的均值(%) | `forecast_accuracy_record.mape` |

**许可误差范围**（GB/T 22482 原则性规定，具体量级按预报对象分）：

| 预报对象 | 许可误差（原则值） | 说明 |
|---------|------------------|------|
| 洪峰流量 | 相对误差 ≤ 20% | `[条款号待核]`，行业通用 |
| 洪峰出现时间 | 绝对误差 ≤ 数小时（按流域规模） | `[条款号待核]` |
| 水位 | 绝对误差 ≤ 0.3m 量级 | `[条款号待核]`，SL 250-2000 同源 |
| 降雨量 | 按量级分级评定 | `[条款号待核]` |

> ⚠️ 上述误差范围是 GB/T 22482 的**原则性规定**，具体到第几条/表格几行需查标准全文核对。本文件暂标 `[条款号待核]`，不编造精确条款号。Agent 引用时述"依 GB/T 22482 精度评定原则"即可，不引用具体条款号。

#### 本系统置信度分级（依据上述原则落地）

```
MAPE < 15%  → 精度置信度 = 高
MAPE 15~30% → 精度置信度 = 中
MAPE > 30%  → 精度置信度 = 低
（阈值 15%/30% 是本系统的落地配置,非标准原文,从 model_config 读）
```

#### 预见期与发布规范

| 要求 | 原则 |
|------|------|
| 预见期标注 | 预报结论须标注预见期（如 24h / 168h），长预见期降置信度 |
| 发布主体 | 洪水预报由水文机构发布，本系统产出的是**辅助决策**而非官方发布 |
| 时效性 | 汛期加密预报频次，预见期内滚动更新 |

### 2.2 GB/T 50587-2018《水库调度设计规范》

**对预报的意义**：规范了防洪/兴利/生态调度的设计方法。预报结论须与调度方式（补偿/错峰/拦洪）衔接。

### 2.3 GB 17621-1998《大中型水电站水库调度规范》

**防洪调度三阶段**（与本系统特征水位越限规则对应）：

```
正常调度：水位 < 汛限 → 按兴利需要调度
非常调度：水位 ≥ 汛限 → 加大泄量，控制水位不超过汛限
紧急调度：水位 ≥ 设计洪水位 → 全力泄洪，确保大坝安全
```

### 2.4 GB/T 50138-2010《水位观测标准》

**对预报的意义**：水位观测精度直接影响预报输入质量。

| 水库等级 | 观测精度要求 |
|---------|-------------|
| 大型 | ±1cm |
| 中型 | ±2cm |
| 小型 | ±5cm |

## 三、行业标准（SL）

### 3.1 SL 250-2000《水文情报预报规范》（行业版）

> 注意：GB/T 22482 是国标版，SL 250 是行标版，两者在预报精度要求上同源。本系统精度阈值参考 SL 250 的误差量级。

| 预报类型 | 精度要求（SL 250 原则值） |
|---------|------------------------|
| 洪峰流量 | 误差 ≤ 20% `[条款号待核]` |
| 洪峰出现时间 | 误差 ≤ 数小时 `[条款号待核]` |
| 洪量 | 误差 ≤ 20% `[条款号待核]` |
| 水位 | 误差 ≤ 0.3m `[条款号待核]` |

### 3.2 SL 61-2015《水文自动测报系统技术规范》

**对预报的意义**：规范实时监测数据质量，预报输入须满足：

| 要求 | 内容 |
|------|------|
| 数据采集频率 | 水位 5min，雨量 5min |
| 数据传输延迟 | ≤ 10min |
| 数据准确率 | ≥ 95% |

> 预报结论引用实时数据时，若数据延迟超阈值或缺失，应降置信度。

### 3.3 SL 104-2015《水利工程水利计算规范》

**调洪演算基本公式**（预报来水 → 水位演算的物理基础）：

```
水量平衡方程:
  I - O = dS/dt

其中:
  I = 入库流量（来自水文预报,st_mx_preset_cal_r type=21）
  O = 出库流量（由泄流建筑物和水位决定）
  S = 蓄水量（由水位-库容关系确定）
  t = 时间
```

### 3.4 SL/Z 520-2014《水库洪水调度方案编制导则》

**洪水调度方案编制内容**（预报支撑预案的框架）：

```
1. 水库基本参数（库容、水位、泄流能力）
2. 防洪标准（设计洪水、校核洪水）
3. 汛期分期调度规则
4. 不同量级洪水的调度方式
5. 水位-泄量关系曲线
6. 预警指标和响应流程
7. 超标准洪水应急措施
```

## 五、预报发布规范

### 5.1 预报结论必备要素

```
依 GB/T 22482 发布规范,预报结论须包含:
  ① 预报对象（水位/流量/降雨）
  ② 预见期（24h / 168h 等）
  ③ 预报值（点估或区间）
  ④ 精度评定（MAPE / 合格率 / 置信度）
  ⑤ 数据来源（NMC / 和风 / 模型）
  ⑥ 发布时间（as_of）
  ⑦ 免责声明（本系统为辅助决策,非官方发布）
```

### 5.2 精度不足时的处理

```
依 GB/T 22482 精度评定原则:
  - 精度数据不足（forecast_accuracy_record 为空）→ 标"精度待评定",不编数字
  - MAPE 超许可误差 → 降置信度,加"误差偏大,谨慎采用"
  - gated_flag=true（精度回灌链路待修复）→ 标"数据可信但需人工复核"
```
