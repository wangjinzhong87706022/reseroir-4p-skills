# 基线测试模板

## 测试说明

本文件包含103个测试问题的基线测试模板。每个问题需要：
1. 向Hermes Agent发送问题
2. 记录Agent的响应
3. 按6个维度评估响应
4. 记录得分和失败原因

## 评估维度

| 维度 | 说明 | 通过条件 |
|------|------|---------|
| E1: SQL正确性 | SQL语法是否正确 | 可直接执行 |
| E2: 数据准确性 | 结果是否与预期一致 | 数量和内容正确 |
| E3: 响应完整性 | 是否包含所有必要信息 | 直接回答问题 |
| E4: 格式规范性 | 输出格式是否清晰 | 使用Markdown |
| E5: 性能优化 | 是否使用时间范围和分页 | 有LIMIT和时间范围 |
| E6: 业务准确性 | 是否符合水利业务逻辑 | 逻辑正确 |

## 预期失败点分析

基于Skill当前实现，以下问题可能失败：

### 高风险失败（预计失败率 > 30%）
- Q62-Q69: 智能综合分析 - 触发词识别可能不完整
- Q78-Q81: 风险评估 - 5因素计算可能错误
- Q85-Q87: 预案触发 - 3条件判断可能错误
- Q88-Q93: 异常场景 - 异常处理可能不完整
- Q99-Q101: 多轮对话 - 上下文可能丢失

### 中风险失败（预计失败率 10-30%）
- Q74-Q77: 跨域关联 - 多SQL查询可能遗漏
- Q82-Q84: 趋势预测 - 线性外推可能错误
- Q102-Q103: 气象预警 - 表列名可能错误

### 低风险失败（预计失败率 < 10%）
- Q1-Q61: 原有问题 - 已优化到99.7%
- Q70-Q73: 告警聚合 - GROUP BY可能错误
- Q94-Q98: 边界场景 - 边界条件可能未覆盖
