## 测试执行流程

### 对每个问题执行以下步骤：

1. **发送问题**
```bash
curl -X POST http://your-hermes-agent-url/api/chat \
  -H "Content-Type: application/json" \
  -d '{"message": "问题内容", "skill": "early-warning"}'
```

2. **记录响应**
保存Agent的完整响应到文件

3. **评估响应**
按6个维度评估：
- E1: SQL正确性 - SQL是否可执行
- E2: 数据准确性 - 结果是否正确
- E3: 响应完整性 - 是否完整回答
- E4: 格式规范性 - 格式是否清晰
- E5: 性能优化 - 是否有时间范围和分页
- E6: 业务准确性 - 逻辑是否正确

4. **记录结果**
填写测试记录表

## 优化迭代流程

1. **运行基线测试** → 记录所有问题的得分
2. **分析失败项** → 识别失败维度和原因
3. **优化Skill** → 修改SKILL.md或相关模块
4. **重新测试** → 验证优化效果
5. **迭代** → 重复2-4直到通过率达标

## 目标

- **第一轮基线**: 预计通过率 ~70%
- **优化后目标**: 通过率 > 90%
- **最终目标**: 通过率 > 95%
